## About Me

I am a **Frontend Developer Junior** and **Systems Engineering student** from Totonicapán, Guatemala.

I have freelance experience building administrative and business-oriented systems using **React, TypeScript, Vite and Tailwind CSS**. My main focus is frontend development, but I also have experience integrating APIs, working with authentication flows, supporting backend tasks and connecting applications with relational databases.

I have worked on collaborative projects using **Git, GitHub and Trello**, leading the frontend side in several systems and supporting backend teams with endpoints, integration logic and database-related workflows.

### POS System for Clothing Store
